# Personal Expenses Tracker

Personal Expenses Tracker is a Python-based application designed to help users manage and track their daily expenses efficiently.

## Features
- Add new expenses
- View expense history
- Track spending records
- Simple and user-friendly interface
- Helps in personal budget management

## Technologies Used
- Python

## Purpose
This project was developed to provide an easy way to monitor personal expenses and improve financial management skills.
